# Calderon_ITE-18---Activity-1-Frontend

## Personal Profile Website

A two-page personal profile website developed using **Nuxt.js** as part of **ITE 18 – Application Development and Emerging Technologies, Activity 1 – My First Nuxt Application (Frontend)**.

The website serves as a personal introduction, presenting basic information, educational background, skills, interests, hobbies, and leadership experiences through a simple and responsive interface.

## Technologies Used

- **Nuxt.js** – Vue-based framework for building the web application
- **Vue.js** – JavaScript framework for building user interfaces
- **HTML** – Structure of the web pages
- **CSS** – Styling and layout
- **JavaScript** – Interactive functionality
- **Tailwind CSS** – Utility-first CSS framework for styling

## Installation and Setup

### Prerequisites

Make sure the following are installed on your computer:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/kieshajaecalderon/Calderon_ITE-18---Activity-1-Frontend.git
```

### 2. Navigate to the Project Folder

```bash
cd Calderon_ITE-18---Activity-1-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
